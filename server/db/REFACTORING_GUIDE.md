# db.ts 拆分重构指南

## 背景

原始 `db.ts` 文件包含 6338 行代码和 244 个导出函数，承载了从数据库连接管理到所有实体 CRUD 的全部职责。v359 版本开始按领域逐步拆分。

## 拆分策略

采用**渐进式代理模式**：先创建子模块文件，将函数按领域分组提取，然后在原始 `db.ts` 中通过 re-export 保持向后兼容。新代码应直接从子模块导入。

## 领域划分

| 子模块 | 函数数量 | 职责 |
| :--- | :--- | :--- |
| `connection.ts` | 3 | 数据库连接池、直连、池状态 |
| `accounts.ts` | 12 | 广告账户 CRUD、默认账户、排序 |
| `campaigns.ts` | 15 | 广告活动 CRUD、分配、批量创建 |
| `adGroups.ts` | 5 | 广告组 CRUD |
| `keywords.ts` | 8 | 关键词 CRUD、批量创建 |
| `targets.ts` | 6 | 投放目标 CRUD |
| `performance.ts` | 15 | 绩效数据、趋势、汇总 |
| `sync.ts` | 30 | 同步任务、队列、调度、日志 |
| `optimization.ts` | 20 | 优化事件、日志、回滚 |
| `bidding.ts` | 12 | 出价调整记录、追踪 |
| `team.ts` | 10 | 团队成员、权限 |
| `notifications.ts` | 8 | 通知设置、历史、邮件 |
| `searchTerms.ts` | 6 | 搜索词分析 |
| `ai.ts` | 12 | AI 优化执行记录 |

## 迁移步骤

1. 新增功能直接在对应子模块中编写
2. 修改现有功能时，将相关函数迁移到子模块
3. 更新导入路径为子模块路径
4. 当某个领域的函数全部迁移后，从 `db.ts` 中移除并在 `db/index.ts` 中 re-export

## 当前状态

v359.0 完成了拆分规划和索引文件创建，实际函数迁移将在后续版本中逐步进行。
