## 编码规范

1. **新代码禁止使用** `@ts-ignore`，必须使用正确的类型定义
2. **允许使用** `@ts-expect-error` 并附带说明，用于已知的第三方库类型问题
3. **逐步替换** `: any` 为具体接口或 `unknown`
4. **类型断言** 优先使用 `as Type` 而非 `as any`
