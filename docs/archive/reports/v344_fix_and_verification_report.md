## 二、P0修复：coldStartService同步天数Bug

### 2.1 问题根因

`coldStartService.ts` 的 `executeFullSync` 函数在调用 `syncService.syncAll()` 时**未传入 `performanceDays` 参数**，导致 `syncAll` 使用默认值14天。此外，后续的 `syncPerformanceOnly` 调用中存在硬编码限制 `days > 30 ? 30 : days`，进一步将绩效数据同步限制在最多30天。

### 2.2 修复内容

```typescript
// 修复前（V343及之前）
const syncData = await syncService.syncAll(); // 默认performanceDays=14
// ...
await syncService.syncPerformanceOnly(days > 30 ? 30 : days); // 硬限制30天

// 修复后（V344）
const syncData = await syncService.syncAll({ performanceDays: days }); // days=90
// 移除了额外的syncPerformanceOnly调用，避免重复同步
```

### 2.3 验证结果

通过生产日志确认修复已生效：
