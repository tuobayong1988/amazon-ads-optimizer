## 2. 核心交付模块详解

### 2.1. 数据库迁移与数据填充

**目标:** 为多租户SaaS架构提供数据库支持,并为机器学习模型提供训练数据。

| 功能点 | 实现方案 | 业务价值 |
| :--- | :--- | :--- |
| **数据库迁移** | 提供了完整的SQL迁移脚本,用于创建多租户相关表(组织、订阅、成员等),并为现有表添加`organizationId`字段。 | 实现了从单租户到多租户架构的平滑过渡,保障了数据模型的完整性和扩展性。 |
| **数据填充** | 创建了TypeScript脚本,可生成6种不同类型的模拟广告活动历史数据(高效、低效、增长、下降、稳定、季节性),共计约540条记录。 | 为机器学习模型的训练和测试提供了高质量、多样化的数据集,解决了冷启动问题。 |
| **自动化脚本** | 提供了`run-migration.sh`脚本,可一键执行数据库备份和迁移,并提供了数据填充脚本的多种执行模式(填充、报告、导出)。 | 简化了部署和数据准备流程,降低了人为操作失误的风险。 |

**技术亮点:**
- 迁移脚本具有幂等性,可以安全地重复执行。
- 数据填充脚本不仅能将数据写入数据库,还能生成统计报告和导出CSV文件,方便数据分析和验证。

### 2.2. 前端UI开发

**目标:** 为机器学习、智能投放和多租户管理三大核心功能提供直观、易用的前端操作界面。

| 交付页面 | 功能描述 | 核心组件 |
| :--- | :--- | :--- |
| **ML优化页面** | 用户可以选择优化目标,为单个广告活动获取出价推荐,或为整个绩效组获取预算分配建议,并能可视化模型性能。 | `Card`, `Select`, `Input`, `Button`, `Alert`, `LineChart` |
| **智能投放页面** | 用户可以选择绩效组,获取批量优化建议,并通过`dry-run`模式安全地预览和执行优化操作。 | `Card`, `Switch`, `Button`, `Table`, `Badge`, `Alert` |
| **组织管理页面** | 提供了多标签页界面,用于管理组织信息、成员、订阅计划和API密钥,并能清晰地展示配额使用情况。 | `Tabs`, `Card`, `Table`, `Dialog`, `Progress`, `Badge` |

**技术亮点:**
- 采用`@tanstack/react-query`和`trpc`进行数据获取和状态管理,代码结构清晰,开发效率高。
- 大量使用`shadcn/ui`组件库,构建了现代化、一致性强且响应式的用户界面。
- 通过对话框(`Dialog`)和表单(`Form`)提供了友好的交互体验,如邀请成员、创建API密钥等。

### 2.3. 集成测试用例

**目标:** 为三大核心功能的后端逻辑编写全面的集成测试,确保代码质量和系统稳定性。

## 4. 如何开始

所有代码和文档均已提交至您的GitHub仓库。

```bash
# 1. 克隆最新代码
git clone https://github.com/tuobayong1988/amazon-ads-optimizer.git
cd amazon-ads-optimizer

# 2. 安装依赖
pnpm install

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 文件,填入数据库连接信息

# 4. 执行数据库迁移
./scripts/run-migration.sh

# 5. 填充ML训练数据
pnpm tsx scripts/seed-ml-training-data.ts all

# 6. 启动应用
pnpm run dev
```

应用启动后,您可以访问以下新页面:
- `/ml-optimization`
- `/smart-campaign-management`
- `/organization-settings`
