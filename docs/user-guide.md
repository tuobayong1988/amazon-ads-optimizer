# Amazon广告优化系统 - 用户指南

## 1. 简介

欢迎使用Amazon广告优化系统! 本系统旨在帮助Amazon卖家和广告商自动化广告数据分析、优化广告活动、提升广告投资回报率(ROI)。通过本系统,您可以轻松管理广告绩效组、跟踪关键指标、预测未来趋势、发现数据异常,并做出更明智的广告决策。

### 主要功能
- **绩效组管理**: 将多个广告活动分组管理,设定统一的优化目标。
- **数据可视化**: 提供多种图表(折线图、柱状图、饼图、雷达图等)直观展示广告表现。
- **趋势预测**: 基于历史数据预测未来7天的广告花费和销售额趋势。
- **异常检测**: 自动识别广告数据中的异常点,及时发现问题。
- **对比分析**: 横向对比多个绩效组的表现,发现优劣。
- **数据导出**: 支持将数据批量导出为Excel、CSV格式,或将图表导出为图片。
- **自动化**: 每日自动从Amazon Ads API同步最新数据。

本指南将详细介绍如何使用系统的各项功能。

## 2. 快速入门

### 2.1 首次登录

首次访问系统时,您需要使用管理员提供的账号和密码进行登录。登录后,系统会引导您完成初始配置。

### 2.2 连接Amazon Ads账户

为了让系统能够访问您的广告数据,您需要授权系统连接到您的Amazon Ads账户。

1.  导航到 **设置 > Amazon Ads集成**。
2.  点击 **连接新账户**。
3.  系统将跳转到Amazon登录页面,请登录您的Amazon广告账户并授权。
4.  授权成功后,系统将自动开始同步您的广告活动数据。

### 2.3 创建第一个绩效组

绩效组是管理和优化广告活动的核心单元。

1.  导航到 **绩效组** 页面。
2.  点击 **创建新绩效组**。
3.  输入绩效组名称(例如, "主推产品线")和描述。
4.  点击 **创建**。

接下来,您可以为这个绩效组添加广告活动并设定优化目标。

## 3. 核心功能详解

### 3.1 绩效组详情页

点击任意绩效组即可进入其详情页面,这是进行数据分析和优化的主要界面。

![绩效组详情页概览](https://via.placeholder.com/800x400.png?text=Performance+Group+Detail+Page)

页面主要包含以下几个部分:
- **核心指标卡片**: 展示总花费、总销售额、ACoS、ROAS等关键指标。
- **绩效趋势图表**: 可视化展示历史和预测数据。
- **广告活动列表**: 显示该组包含的所有广告活动及其表现。
- **优化日志**: 记录系统的自动优化操作。

### 3.2 管理广告活动

您可以随时向绩效组中添加或移除广告活动。

- **添加广告活动**: 在详情页的广告活动列表上方,点击 **添加广告活动** 按钮,在弹出的对话框中选择要添加的广告活动。
- **移除广告活动**: 在广告活动列表中,点击对应广告活动右侧的 **移除** 按钮。

### 3.3 设定优化目标

为绩效组设定明确的优化目标,可以帮助系统更智能地提供建议和自动优化。

1.  在详情页右上角,点击 **编辑目标**。
2.  在弹出的对话框中,您可以选择优化目标类型,例如:
    - **销售最大化**: 在预算内尽可能提高销售额。
    - **目标ACoS**: 将广告成本销售比控制在特定目标值。
    - **目标ROAS**: 将广告投资回报率维持在特定目标值。
3.  根据所选目标类型,填写相应的目标值(例如, 目标ACoS为25%)。
4.  您还可以设定每日预算上限和最高出价建议。
5.  点击 **保存**。

## 4. 数据分析与可视化

### 4.1 使用绩效趋势图表

绩效趋势图表是系统中最核心的分析工具。您可以通过图表右上角的控制器进行交互。

![图表控制器](https://via.placeholder.com/600x150.png?text=Chart+Controls)

- **图表类型切换**: 您可以在 **折线图、柱状图、面积图、组合图、饼图、雷达图** 之间切换,以从不同维度观察数据。
- **时间范围选择**: 选择查看 **最近7天、30天或90天** 的数据。

### 4.2 趋势预测

勾选 **显示预测** 复选框,图表上将出现未来7天的趋势预测线(虚线部分)。

- **预测解读**: 预测线可以帮助您判断未来一段时间内花费和销售额的大致走向,辅助您进行预算规划和备货决策。
- **置信区间**: 预测线周围的阴影区域代表预测的置信区间,表示预测结果可能波动的范围。

### 4.3 异常检测

勾选 **显示异常** 复选框,图表上将出现红色圆点标记,表示系统检测到的数据异常点。

- **异常解读**: 将鼠标悬停在异常点上,可以查看异常的详细信息,如异常类型(例如, "峰值"或"谷值")和严重程度。
- **异常处理**: 发现异常后,您可以深入排查对应日期的广告活动,分析是什么原因导致了数据的剧烈波动(例如, 季节性活动、断货、广告设置重大更改等)。

### 4.4 对比分析

在 **绩效组** 列表页面,点击 **对比分析** 按钮,可以进入对比分析模式。

1.  选择2至5个您想要对比的绩效组。
2.  选择对比的 **核心指标** (例如, 销售额)。
3.  选择 **图表类型** (折线图、柱状图或雷达图)。

系统将生成对比图表和统计数据,帮助您直观地比较不同产品线或广告策略的表现优劣。

## 5. 数据导出

系统提供了强大的数据导出功能,方便您进行离线分析或制作报告。

### 5.1 导出单个绩效组数据

在绩效组详情页,点击图表右上角的 **导出** 按钮,可以选择:
- **导出为CSV**: 将图表下方的表格数据导出为CSV文件。
- **导出为Excel**: 将数据导出为格式更丰富的Excel文件。
- **导出为PDF**: 将包含图表和数据的整个页面视图导出为PDF文件。

### 5.2 批量导出

在 **绩效组** 列表页面,点击 **批量导出** 按钮:
1.  选择您想要导出的所有绩效组。
2.  选择导出格式:
    - **Excel**: 将所有选定组的数据导出到一个Excel文件中,每个组一个工作表(Sheet)。
    - **CSV**: 将每个组的数据分别导出为CSV文件,并打包成一个ZIP压缩包。
3.  选择时间范围。
4.  点击 **开始导出**。

### 5.3 导出图表为图片

在绩效组详情页,点击图表右上角的 **导出** 按钮,然后选择 **导出图表为PNG** 或 **导出图表为SVG**。这对于在演示文稿或报告中插入高质量图表非常有用。

## 6. 常见问题 (FAQ)

**Q1: 数据多久更新一次?**

A1: 系统默认在每天凌晨2点自动从Amazon Ads API同步前一天的数据。您也可以在绩效组详情页手动触发即时同步,但请注意Amazon API的数据有数小时的延迟。

**Q2: 为什么我无法选择某些广告活动添加到绩效组?**

A2: 一个广告活动只能属于一个绩效组。如果您想将其添加到一个新的组,需要先从原来的组中移除。

**Q3: 趋势预测的准确性如何?**

A3: 趋势预测是基于历史数据的统计模型,旨在提供一个未来趋势的参考,而非精确预测。其准确性受历史数据长度、稳定性和季节性等多种因素影响。请结合您的业务经验进行决策。

**Q4: 异常检测出的"异常"一定代表有问题吗?**

A4: 不一定。"异常"仅表示该数据点显著偏离了近期的平均水平。这可能是由促销活动(如Prime Day)、断货、广告预算或出价的重大调整等正常商业活动引起的。异常检测工具的目的是提醒您关注这些剧烈变化,并分析其背后的原因。
